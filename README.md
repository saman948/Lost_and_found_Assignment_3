# Campus Lost and Found Portal

## 1. Project Title
Campus Lost and Found Portal

## 2. Project Description
The Campus Lost and Found Portal is a Python-based application designed to help university students report, search for, and recover lost belongings. It provides a centralized system where users can report lost or found items, search existing records, and submit claims to recover their belongings. The purpose of this project is to make the lost and found process more organized, convenient, and efficient within a university campus.

## 3. Features
- User registration and login.
- Reporting lost and found items.
- Searching for reported items.
- Submitting claims for found items.
- Reviewing and approving or rejecting claims.
- Updating the status of recovered items.
- Generating and exporting reports.
- Saving and loading data using JSON files.

## 4. Technologies Used
- **Python:** Main programming language.
- **JSON:** Used for storing application data.
- **Jupyter Notebook:** Development and execution environment.

## 5. How to Run
1. Download or clone the repository.
2. Install Python and Jupyter Notebook.
3. Open the project folder and launch Jupyter Notebook.
4. Open `Campus_Portal_Notebook.ipynb`.
5. Select **Kernel → Restart & Run All** to execute the notebook.
6. Run `main()` in the interactive portal cell to start using the system.

## 6. Project Files
- **Campus_Portal_Notebook.ipynb:** Contains the complete Python code, explanations, demonstrations, and automated tests.
- **data/portal_data.json:** Stores user information, item records, and claims.
- **README.md:** Contains the project overview and instructions.
